## Goals

This repo is intended as a foundation for building and experimenting with a CAD-style workflow in Python, such as:
- geometry primitives + transforms
- sketch/shape construction
- scene/model representation
- export pipelines (eventually: SVG/DXF/STL/OBJ-style outputs)

> The exact feature set depends on what’s implemented in `src/` right now—OpenCad is in a prototyping phase.
